# 11 Hello World

你必須已經「不需要解釋」就能看懂：

```python
print('Hello, World!')
```

用途：

- 驗證環境正常
- 最小可執行程式

## 註釋版範例（可直接貼到程式）

```python
# 1) 最小可執行程式：確認 Python 可正常執行
print("Hello, World!")

# 2) 變數 + 輸出：把資料組合成訊息
name = "Python"
print("Hello,", name)

# 3) 輸入 + 輸出：解題常見的 I/O 入口
# 在終端輸入一行文字，例如：Amy
# 程式會輸出：Hello, Amy
user_name = input()
print(f"Hello, {user_name}")
```
